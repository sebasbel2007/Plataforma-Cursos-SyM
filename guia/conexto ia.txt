- PDFs certificados: el profesor pega link de Google Drive; el sistema NO personaliza el PDF
- Reproductor: video HTML5 nativo con controlsList="nodownload"
- Progreso del alumno: se guarda en Firestore como array de módulos completados
- Reembolso: se habilita solo si `modulosCompletados / totalModulos < 0.5`
- Notificaciones: Firestore `onSnapshot` listeners, colección `notifications/{userId}`
- Roles: guardados en Firestore `users/{uid}.role` = "student" | "teacher" | "admin"
- Pagos: Mercado Pago Checkout Pro, redirect a sandbox_init_point, resultado en checkout-result.html
- Split: 70% profesor / 30% plataforma, registrado en `transactions` de Firestore

## FLUJOS DE USUARIO

### Flujo Alumno
```
Visita index.html (catálogo)
  → Sin sesión: ve cursos, no puede comprar
  → Clic en curso → course-detail.html
      → Clic "Comprar" → redirect a login.html (si no tiene sesión)
      → login.html / register.html → vuelve a checkout.html
  → checkout.html: resumen + acepta términos + pago Mercado Pago
  → Pago aprobado → enrollment creado en Firestore → redirect a course-player.html
  → course-player.html:
      Clase 1 (video + texto) → Quiz módulo 1 (obligatorio) → Clase 2...
      Al completar todos los módulos → course-exam.html
  → course-exam.html: examen final → si aprueba → certificado disponible
  → dashboard-student: ver progreso, historial, dejar reseña
```

### Flujo Profesor
```
register.html → selecciona rol "Profesor"
  → redirect a checkout.html (membresía $20.000 ARS)
  → Pago aprobado → role = "teacher" en Firestore
  → dashboard-teacher/index.html
  → course-editor.html: llena datos del curso
      → Guarda borrador (status: "draft")
      → Envía a moderación (status: "pending")
  → Admin aprueba → status: "published" → notificación al profesor
  → stats.html: ve ventas, ingresos, alumnos
```

### Flujo Admin
```
login.html → role = "admin" → redirect a dashboard-admin/index.html
  → moderation.html: ve cursos en status "pending"
      → Aprueba → status: "published" + notificación al profesor
      → Rechaza → status: "rejected" + motivo + notificación al profesor
  → users.html: gestiona cuentas
  → finances.html: ve transacciones, procesa reembolsos
```

## SISTEMA DE ROLES Y GUARDS

### Guards de ruta (app.js)
Cada página protegida verifica al cargar:
```
1. ¿Hay sesión activa? → No → redirect login.html
2. ¿El rol del usuario coincide con la página? → No → redirect index.html
```

| dashboard-student/ | student |
| dashboard-teacher/ | teacher |
| dashboard-admin/ | admin |

## LÓGICA DE REEMBOLSO

```
progressPercent = (completedModules.length / course.totalModules) * 100

if (progressPercent < 50) → refundEligible = true
else → refundEligible = false
```

- El alumno solicita reembolso desde dashboard-student
- Admin lo procesa desde finances.html
- Al aprobar: `transaction.status = "refunded"`, `enrollment` marcado como reembolsado
- Notificación a alumno y profesor

totalAmount = course.price (en ARS)

```

- Se guarda en `transactions/{id}` al confirmar el pago

# SCHEMA-BDD.md — Cursos SyM
# Esquema de colecciones Firestore
# Todos los campos, tipos y relaciones

---

## COLECCIÓN: `users`
**Documento ID:** `{uid}` (Firebase Auth UID)

```
users/{uid}
├── uid: string
├── email: string
├── displayName: string
├── photoURL: string | null
├── role: "student" | "teacher" | "admin"
├── membershipStatus: "none" | "active" | "expired"   // solo teachers
├── membershipPaidAt: timestamp | null
├── createdAt: timestamp
├── suspended: boolean
└── suspendedReason: string | null
```

---

## COLECCIÓN: `courses`
**Documento ID:** auto-generado

```
courses/{courseId}
├── courseId: string
├── teacherId: string                    // ref a users/{uid}
├── teacherName: string
├── title: string
├── subtitle: string
├── description: string                  // texto largo
├── category: string
├── tags: array<string>
├── requirements: array<string>          // qué necesita saber el alumno
├── outcomes: array<string>              // 3-5 resultados esperados
├── price: number                        // en ARS, 0 = gratis
├── isFree: boolean
├── thumbnailURL: string                 // URL externa (Cloudinary)
├── promoVideoURL: string                // URL YouTube
├── totalModules: number
├── totalDuration: string                // ej. "4h 30min" (calculado)
├── status: "draft" | "pending" | "published" | "rejected"
├── rejectionReason: string | null
├── certificateURL: string               // URL Google Drive (PDF plantilla)
├── rating: number                       // promedio calculado
├── totalRatings: number
├── totalStudents: number
├── createdAt: timestamp
└── updatedAt: timestamp
```

---

## SUBCOLECCIÓN: `courses/{courseId}/modules`
**Documento ID:** auto-generado (ordenar por `order`)

```
courses/{courseId}/modules/{moduleId}
├── moduleId: string
├── order: number                        // 1, 2, 3... (máx 15)
├── title: string
└── lessons: array<{                     // array embebido dentro del módulo
      lessonId: string,
      order: number,
      title: string,
      videoURL: string,                  // URL YouTube
      content: string                    // texto de apoyo (markdown o HTML)
    }>
```

---

## SUBCOLECCIÓN: `courses/{courseId}/modules/{moduleId}/quiz`
**Documento ID:** fijo `"quiz"` (uno por módulo)

```
courses/{courseId}/modules/{moduleId}/quiz/quiz
├── questions: array<{
      questionId: string,
      text: string,
      options: {
        a: string,
        b: string,
        c: string,
        d: string
      },
      correctOption: "a" | "b" | "c" | "d"
    }>
└── passingScore: number                 // % mínimo para aprobar (ej. 70)
```

---

## SUBCOLECCIÓN: `courses/{courseId}/finalExam`
**Documento ID:** fijo `"exam"`

```
courses/{courseId}/finalExam/exam
├── questions: array<{
      questionId: string,
      text: string,
      options: {
        a: string,
        b: string,
        c: string,
        d: string
      },

# Cursos SyM — Plataforma de Educación Online

Marketplace de cursos online con sistema de roles, evaluación integrada y pasarela de pagos.  
Proyecto escolar — Desarrollo web con servicios en la nube.

---

## Stack Tecnológico

| Capa | Tecnología |
|---|---|
| Frontend | HTML5, CSS3, Vanilla JS |
| Auth | Firebase Authentication |
| Base de Datos | Firebase Firestore |
| Almacenamiento (temp) | YouTube (videos), Google Drive (PDFs) |
| Pagos (temp) | Mercado Pago Sandbox |
| Hosting | GitHub Pages |

> **Temporal:** YouTube y Drive serán reemplazados por una solución de almacenamiento definitiva en la etapa final. Mercado Pago Sandbox será configurado con credenciales reales al finalizar.

---

## Roles de Usuario

- **Alumno** — Registro gratuito. Compra cursos individuales. Consume contenido, hace quizzes y examen final. Obtiene certificado PDF.
- **Profesor** — Membresía única de $20.000 ARS. Crea y publica cursos. Recibe 70% de cada venta. Sus cursos pasan por moderación antes de publicarse.
- **Administrador** — Control total. Modera cursos, gestiona usuarios y finanzas.

---

## Reglas de Negocio Clave

- Split de pagos: **70% Profesor / 30% Plataforma** (fijo, no configurable)
- Membresía profesor: **$20.000 ARS** (pago único)
- Precio de cursos: **$0 (gratis) hasta $500 USD en ARS**
- Reembolso: permitido solo si el alumno consumió **menos del 50% de los módulos**
- Cursos: máximo **15 módulos** por curso
- Quiz por módulo: **obligatorio** para avanzar al siguiente
- Examen final: **multiple choice**, corrección automática
- Todo curso (incluso gratuito) pasa por **moderación del Admin** antes de publicarse
- Categorías y etiquetas: creadas por **Admin y Profesores**
- Notificaciones in-app: **tiempo real** (Firestore listeners)
- Correos transaccionales: **pendiente** (se implementa con la pasarela definitiva)
- Idioma: **Español únicamente**

---

## Diseño y UI

- Modo claro y oscuro con toggle (botón en esquina desktop / menú lateral mobile)
- Logo cambia según el modo: `logo-claro.png` / `logo-oscuro.png`
- Paleta: fondos gris oscuro/negro, texto blanco, acento azul/cian neón suave
- Layout: **Bento Grid** para dashboards y paneles
- Tarjetas de cursos: esquinas redondeadas, miniatura, barra de progreso, efecto apilamiento si hay múltiples en categoría
- Menú lateral fijo (desktop) / desplegable (mobile)
- Tipografía sans-serif moderna, contraste claro entre títulos e info secundaria
